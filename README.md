# FAQ Frequently Asked Questions - Legion Killfeed

## What is a killfeed in DayZ?
A killfeed tracks and displays player kills, deaths, and other significant in-game events as close to real-time as Nitrado allows. Killfeeds are commonly used on DayZ servers to give players and admins clear information about combat and server activity.

> [!NOTE]
> DayZ console killfeeds depend on Nitrado log updates. Legion processes the data as soon as those logs are available.

## Why should I use a killfeed for my DayZ server?
Using a killfeed like [Legion Killfeed](https://killfeed.co) improves player experience, server transparency, and admin oversight. It helps administrators monitor in-game activity while allowing players to track kills, deaths, performance, and major server events.

## How does Legion Killfeed differ from other killfeeds?
Legion Killfeed, available at [Killfeed.co](https://killfeed.co), is built specifically for DayZ console servers and integrates directly with Discord. It offers semi-real-time feeds, visual PVP and PVE data, stats, leaderboards, heatmaps, base radars, ticket tools, server tools, automation, economy features, and broad customization without feature paywalls.

> [!NOTE]
> Legion is designed for Xbox and PlayStation DayZ servers using Nitrado-hosted console logs.

## Can I customize the events tracked by Legion Killfeed?
Yes, [Legion Killfeed](https://killfeed.co) is highly customizable. You can configure tracked events, feed channels, embed colours, server branding, logos, economy settings, bounty settings, alerts, and other server-specific options.

## How do I set up Legion Killfeed on my DayZ server?
Setting up [Legion Killfeed](https://killfeed.co) is straightforward. After subscribing, link Ko-Fi to Discord, join the Legion Discord, invite the bot, then follow the setup flow. Legion detects your subscription role, activates your commands, and provides setup instructions. Most setup is handled through two main commands, with the bot doing most of the channel and permission work.

## Does Legion delete anything?
Absolutely not. [Legion Killfeed](https://killfeed.co) is designed to create channels and manage its own setup output. The only messages it deletes are its own setup or command-related messages, mainly to reduce spam. Legion does not have [message intents](https://support-dev.discord.com/hc/en-us/articles/4404772028055-Message-Content-Privileged-Intent-FAQ) enabled, so it cannot freely read normal user messages. Without that intent, the bot only sees the member information required for linking, assigning admin, adding roles, and similar Discord functions. Anyone claiming it can do otherwise is spreading misinformation about how Discord bot permissions and privileged intents work.

> [!CAUTION]
> Claims that Legion can freely read, delete, or interfere with normal Discord messages are not how Discord privileged intents work.

## Can I use Legion Killfeed with other DayZ bots and tools?
Yes, [Legion Killfeed](https://killfeed.co) can run alongside other DayZ bots and Discord tools. Legion cannot affect another bot, and another bot cannot affect Legion unless server permissions are deliberately configured in a way that allows role or channel interference.
